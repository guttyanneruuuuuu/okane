# のんびり農場ガチャ (Idle Farm Gacha)

シンプルで明るい雰囲気の **放置 × ガチャ** ブラウザゲーム。  
完全無料運営を前提に、静的ファイルのみで動作する設計（localStorage 保存・サーバー不要）。

## 🎮 ゲーム概要

- **ジャンル**: 放置(Idle / Incremental) × ガチャ収集
- **舞台**: のどかな牧場
- **目標**: ガチャで動物を集めて、自動で生産物（コイン）を増やし、図鑑をコンプリートする
- **AI 不使用**・**ネオン系UIなし** ・ アクセシブルで明るい配色

## ✨ 主な特徴

| 機能 | 内容 |
| ---- | ---- |
| 自動収穫 | 動物を配置すると時間経過で自動でコイン獲得（オフライン中も進行） |
| ガチャ | コインを消費して動物を引く（無料 = 完全F2Pフレンドリー） |
| レアリティ | ★1 〜 ★5、レアほど生産力が高い |
| 図鑑 | コレクション要素。同じ動物を重ねるとレベルアップ |
| プレステージ | 長期目標。リセットで永続強化を獲得 |
| 広告枠 / 課金枠 | UIプレースホルダ実装。将来のアプリ展開時に差し込める設計 |

## 🛠 技術スタック

- **HTML / CSS / Vanilla JavaScript のみ**（フレームワーク不使用）
- **localStorage** によるセーブ
- ビルド不要 → どの静的ホスティングサービス（Cloudflare Pages, GitHub Pages, Netlify など）でも無料公開可能

## ▶️ ローカル起動

```bash
# プロジェクトルートで
python3 -m http.server 8000
# → http://localhost:8000 を開く
```
